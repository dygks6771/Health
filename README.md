# 러너스 크로니클 (Health RPG)

실제로 달린 거리로 영웅을 키우는 중세 판타지 RPG. 삼성헬스 등의 러닝·걸음 기록을 Health Connect 로 읽어 경험치·행동력으로 바꾼다.

- `app/` — Android 앱 (Kotlin, Jetpack Compose, Health Connect)
- `server/` — 게임 서버 (Spring Boot + PostgreSQL) — 규칙·API: [server/README.md](server/README.md)
- `docs/RELEASE.md` — **출시 가이드** (서버 HTTPS 배포, 서명, Play Console)

## 개발 환경 실행 (Windows PC + 폰)

1. Docker Desktop 실행 → `cd server` → `docker compose up -d` (개발용 DB)
2. `.\gradlew.bat bootRun` (서버). 콘솔에 폰에서 쓸 주소가 출력됨
3. 안드로이드 스튜디오에서 ▶ 실행 (debug 빌드)
4. 앱 로그인 화면 → 서버 설정에 콘솔에 나온 주소 입력 (USB 면 `adb reverse tcp:8080 tcp:8080` 후 `http://127.0.0.1:8080`)
5. 폰의 **삼성헬스 → 설정 → Health Connect** 연동 켜기, 앱에서 운동·거리·걸음 수 읽기 허용

debug 빌드는 http 주소와 서버 주소 변경을 허용하고, release 빌드는 `gradle.properties` 의 `releaseServerUrl`(https)로만 접속한다.

## 앱 구성 (중세 판타지 · 모험자 길드 컨셉)

1. **로그인 / 회원가입** → 2. **영웅 생성** (외형 6종 · 직업 5종 · 이름) → 3. **로비**
- **로비**: 영웅 → 이번 주 원정 → 출석 상자 → 원정 지도 → 장비 순. 하단 바로가기(**모험 · 길드 · 레이드 · 영웅·가방**), 나머지는 우측 상단 **☰ 메뉴**. 첫 러닝 전에는 모험가 안내서 표시
- **모험**: 초보자 마을 ~ 마왕성 외곽 10개 지역 던전 (장비 드롭)
- **모험자 길드**: 매일 바뀌는 토벌 의뢰 5개
- **레이드**: 주 1회, 친구 4명과 고대 마룡 토벌(4단계 진화 도트), 데미지에 따라 F~S 등급
- **상점**: 골드로 무기 / 방어구 뽑기 (상인 NPC)
- **경매장**: 유저끼리 장비 사고팔기 (경매인 NPC)
- **랭킹**: 전체 모험가 순위
- **대장간**: 장비 강화 (+25, 실패 시 +5 이상은 1단계 하락)
- **영웅 · 가방**: 능력치 찍기, 장착·판매
- **친구**: 영웅 이름으로 친구 요청, 용병 친구 모집
- **설정**: 지금 동기화·최근 러닝 기록, 알림 켜기/끄기, 개인정보처리방침, 로그아웃·회원 탈퇴 (개발 빌드만 서버 주소)
- **알림**: 레벨 업, 주간 원정 달성, 주말 저녁 남은 거리 리마인더
- **주간 원정**: 지난 기록 기반 개인 맞춤 주간 거리 목표, 달성 시 보상 상자, 연속 달성(🔥) 보너스, 요일별 거리 그래프
- **원정 지도**: 누적 러닝 거리로 새 지역 개척 (최장 거리·최고 페이스 기록 표시)
- **레이드 = 함께 달리기**: 파티원 각자의 이번 주 러닝 거리가 데미지 배율 (×0.5~×1.5)
- **자동 동기화**: 앱을 열 때 즉시, 로비에서 5분마다, 앱이 꺼져 있으면 15분마다 백그라운드. 서버 연결 실패 시 인터넷이 연결되면 다시 시도
- **USB 없이 연결 (개발 빌드)**: 같은 와이파이 또는 Tailscale(밖에서)로 PC 서버에 접속. 서버 콘솔에 폰에서 쓸 주소가 출력됨 (`server/README.md` "폰 연결")

토벌·던전·레이드를 하면 **전투 장면**(영웅 돌진·적의 반격·데미지 숫자·양쪽 체력 바·마룡 진화와 브레스)이 재생되고, **패배할 수도 있음**. 승리하면 **보물 상자**가 열리며 보상 획득. 로비에서 하루 한 번 **출석 상자** (`ui/battle/`).

그래픽은 그림 파일 없이 코드로 그린 도트(`ui/sprites/`): 영웅(직업 5 × 외형 6), 장비 아이콘, 몬스터, NPC 4명, 마룡 4단계.

게임 규칙과 API 는 [server/README.md](server/README.md) 참고. **러닝 km → 경험치·골드 (하루 10km 초과분 절반)**, **걸음수 → 행동력 (하루 150)**.
